Zen Home pour Xiaomi Mi Box 4 et TV TCL Google TV

Mode d'emploi de l'application pour Mac. Télécharger l'application

Ce que fait l'application

  • Elle installe Zen Home sur votre box : un écran d'accueil simple et rapide, avec une belle photo, l'heure, la météo, les films du moment et vos applis.
  • Elle allège la box : elle désactive les programmes qui servent à la publicité, au pistage ou qui tournent pour rien.
  • C'est vous qui choisissez : rien n'est modifié avant votre clic sur « Appliquer », après un récapitulatif.
  • C'est réversible : les programmes sont désactivés, pas supprimés, et « Revenir à avant Zen Home » remet la box comme elle était. Seule exception : les applis que vous cocheriez vous-même pour les désinstaller ne reviennent pas (et leurs données non plus).
  • Plusieurs box ? L'application peut les configurer d'affilée, avec les mêmes choix pour toutes.

Ce qu'il vous faut

  • Un Mac (macOS 12 ou plus récent) avec une connexion Internet.
  • Une Xiaomi Mi Box 4 ou une TV TCL Google TV, allumée et branchée sur le même Wi-Fi que le Mac. Un autre appareil Android TV ou Google TV n'est peut-être pas encore pris en charge : l'application peut alors préparer un « rapport d'appareil » (simple lecture) à m'envoyer.
  • La télécommande de la box ou de la TV.

Étape 1 : préparer la box ou la TV

Tout se fait avec la télécommande. Les menus changent un peu selon l'appareil ; l'application vous montre le bon chemin quand vous choisissez votre appareil.

A. Débloquer les options cachées

Xiaomi Mi Box :

  1. Ouvrez Paramètres (la roue dentée).
  2. Allez dans Préférences de l'appareil, puis À propos.
  3. Descendez jusqu'à Build et appuyez 7 fois sur OK, jusqu'au message « Vous êtes maintenant développeur ».

TV TCL Google TV :

  1. Ouvrez Paramètres, puis Système, puis À propos.
  2. Descendez jusqu'à Build de l'OS Android TV et appuyez 7 fois sur OK, jusqu'au message « Vous êtes maintenant développeur ».

B. Activer le débogage USB

Xiaomi Mi Box :

  1. Revenez en arrière, dans Préférences de l'appareil.
  2. Ouvrez Options pour les concepteurs (parfois appelé « Options pour les développeurs »).
  3. Activez Débogage USB.

TV TCL Google TV : revenez dans Système, ouvrez Options pour les développeurs et activez Débogage USB.

C. Noter l'adresse IP de l'appareil (au cas où)

L'application cherche elle-même l'appareil. Son adresse ne sert que si la recherche échoue. Sur la Mi Box : Préférences de l'appareil, À propos, État, puis Adresse IP ; sur la TV : dans Réseau et Internet, en ouvrant votre réseau Wi-Fi (par exemple 192.168.1.23).

Étape 2 : installer l'application sur le Mac

  1. Double-cliquez sur le fichier Zen-Home-Mac.dmg téléchargé.
  2. Dans la fenêtre qui s'ouvre, glissez « Zen Home » dans le dossier Applications.
  3. Ouvrez Zen Home depuis le dossier Applications.

Si macOS bloque l'application

Au premier lancement, un message du type « Apple ne peut pas vérifier que Zen Home ne contient pas de logiciel malveillant » est normal : l'application ne vient pas de l'App Store et n'est pas enregistrée auprès d'Apple.

  • macOS 15 et plus récent : fermez le message, ouvrez Réglages Système, Confidentialité et sécurité, descendez tout en bas jusqu'au message sur « Zen Home » et cliquez sur Ouvrir quand même. Confirmez avec votre mot de passe si on vous le demande.
  • Versions plus anciennes : faites un clic droit (ou Contrôle + clic) sur « Zen Home » dans Applications, choisissez Ouvrir, puis Ouvrir dans la fenêtre qui s'affiche.

Il ne faut le faire qu'une fois. macOS peut ensuite demander si Zen Home peut trouver des appareils sur votre réseau local : acceptez, c'est ce qui permet de retrouver la box.

Étape 3 : suivre l'application

Cliquez sur Commencer et laissez-vous guider. Comptez une dizaine de minutes ; gardez la TV et la box allumées tout du long.

  1. La première fois, l'application propose de télécharger l'outil officiel de Google « adb » (environ 18 Mo, vérifié automatiquement). Il reste rangé dans les fichiers de l'application.
  2. Elle cherche la box sur le réseau (jusqu'à une quinzaine de secondes) et vous la montre par son nom, par exemple « SALON ». S'il y en a plusieurs, cochez celles à configurer, ou « Tout sélectionner ». Si aucune n'est trouvée, saisissez l'adresse IP notée à l'étape 1.
  3. Sur la TV, un message demande d'autoriser le Mac : cochez « Toujours autoriser cet ordinateur » puis validez.
  4. L'application enregistre une sauvegarde de l'état de la box, sans rien modifier, puis vous pose quelques questions.
Votre ville (facultatif)
Pour afficher la météo. Le nom de la ville est envoyé au service gratuit Open-Meteo pour trouver sa position.
Les films
Les films du moment et leurs bandes-annonces sont inclus : il n'y a rien à faire, et aucun compte à créer. Si vous préférez, vous pouvez utiliser votre propre jeton TMDB (facultatif) : créez un compte sur www.themoviedb.org, ouvrez Paramètres puis API, copiez le « API Read Access Token » (un très long texte) et collez-le dans l'application (option « Utiliser mon propre jeton TMDB »). Il n'est jamais enregistré sur le Mac. Films fournis par TMDB ; ce produit utilise l'API TMDB mais n'est ni approuvé ni certifié par TMDB.
Alléger votre box
La liste des programmes à désactiver, rangés par groupes, avec une explication pour chacun. Le choix recommandé est coché d'avance ; décochez ce que vous voulez garder.
Vos applis
Les applis que vous avez installées. Rien n'est coché d'avance. Ne cochez que celles que vous voulez vraiment désinstaller : c'est définitif.
Le récapitulatif
Rien n'est modifié avant votre clic sur Appliquer.

À la fin, l'écran « Zen Home est prêt » résume ce qui a été fait, et la TV affiche Zen Home.

Après coup

Après une mise à jour de la box

Une mise à jour peut réactiver certains programmes ou remettre l'ancien accueil. Réactivez le débogage USB si vous l'aviez coupé, ouvrez Zen Home et choisissez Réparer sur l'écran d'accueil. Vos choix précédents sont conservés. L'application se souvient de vos box : elle les retrouve en quelques secondes.

Revenir en arrière

Choisissez Revenir à avant Zen Home sur l'écran d'accueil. L'application remet la box comme dans la sauvegarde prise avant la première installation : les programmes désactivés par Zen Home reviennent, l'accueil d'origine aussi, et Zen Home est retiré de la TV. Les applis que vous aviez désinstallées ne reviennent pas.

Les sauvegardes

Les sauvegardes et rapports sont rangés dans les fichiers de l'application. Le bouton Ouvrir les sauvegardes, à la fin d'une installation, vous y emmène. Gardez-les si vous demandez de l'aide.

Retirer l'application du Mac

Utilisez Désinstaller de ce Mac, en bas de l'écran d'accueil : l'application vous propose de garder les sauvegardes dans Documents (recommandé), puis se met à la Corbeille. Votre box n'est pas modifiée : pour retirer Zen Home de la TV, choisissez d'abord « Revenir à avant Zen Home ».

Sécurité : coupez le débogage USB

Tant que le débogage USB est activé, un appareil de votre réseau Wi-Fi qui a été autorisé peut piloter la box. À la fin, l'application vous propose de le couper : acceptez. Vous pourrez le réactiver (même chemin qu'à l'étape 1) pour utiliser « Réparer » ou « Revenir à avant Zen Home ».
