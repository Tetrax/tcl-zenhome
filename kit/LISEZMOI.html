Zen Home pour Xiaomi Mi Box 4

Mode d'emploi du kit d'installation pour Mac.

Ce que fait ce kit

  • Il installe Zen Home, un écran d'accueil simple et rapide : une belle photo, l'heure, la météo, les films du moment et vos applis.
  • Il allège la box : il désactive les programmes qui servent à la publicité, au pistage ou qui tournent pour rien.
  • C'est vous qui choisissez : le kit vous pose des questions avant de toucher à quoi que ce soit, et vous montre un récapitulatif avant d'appliquer.
  • C'est réversible : les programmes sont désactivés, pas supprimés, et le choix « Tout annuler » remet la box comme avant. Seule exception : les applis que vous cocheriez vous-même pour les désinstaller ne reviennent pas (et leurs données non plus).

Ce qu'il vous faut

  • Un Mac avec une connexion Internet.
  • Une Xiaomi Mi Box 4, allumée et branchée sur le même Wi-Fi (ou le même réseau) que le Mac.

Étape 1 : préparer la box

Tout se fait avec la télécommande de la box.

A. Faire apparaître les options développeur

  1. Ouvrez Paramètres (la roue dentée).
  2. Allez dans Préférences de l'appareil, puis À propos.
  3. Descendez jusqu'à Build et appuyez 7 fois sur OK. Un message indique que vous êtes maintenant développeur.

B. Activer le débogage USB

  1. Revenez en arrière, dans Préférences de l'appareil.
  2. Ouvrez Options pour les développeurs.
  3. Activez Débogage USB.

C. Noter l'adresse IP de la box

  1. Préférences de l'appareil, puis À propos, puis État.
  2. Notez l'adresse IP : quatre nombres séparés par des points, par exemple 192.168.1.23.

Étape 2 : lancer le kit sur le Mac

  1. Décompressez l'archive (double-clic sur le fichier .zip). Un dossier ZenHome-MiBox4-… apparaît.
  2. Ouvrez ce dossier et double-cliquez sur « Zen Home.command ». Une fenêtre Terminal s'ouvre : laissez-la ouverte, elle montre ce qui se passe.

Si macOS bloque le fichier

Un message du type « impossible de vérifier le développeur » est normal : le kit ne vient pas de l'App Store. Vous pouvez en lire le contenu, c'est un simple fichier texte.

  • macOS 15 et plus récent : fermez le message, ouvrez Réglages Système, Confidentialité et sécurité, descendez tout en bas jusqu'au message sur « Zen Home.command » et cliquez sur Ouvrir quand même. Confirmez avec votre mot de passe si on vous le demande.
  • Versions plus anciennes de macOS : faites un clic droit (ou Contrôle + clic) sur « Zen Home.command », choisissez Ouvrir, puis Ouvrir dans la fenêtre qui s'affiche.

Solution de secours

  1. Ouvrez l'application Terminal (Applications, Utilitaires, Terminal).
  2. Tapez bash puis un espace (sans appuyer sur Entrée).
  3. Glissez le fichier « Zen Home.command » depuis le Finder dans la fenêtre du Terminal : son chemin s'écrit tout seul.
  4. Appuyez sur Entrée.

Étape 3 : suivre les fenêtres

Le kit vous parle par des fenêtres macOS. Lisez-les, elles expliquent chaque choix.

  1. Choisissez Installer ou modifier mes choix (la première fois).
  2. Si l'outil officiel de Google « adb » n'est pas sur votre Mac, le kit propose de le télécharger (environ 18 Mo, vérifié automatiquement). Rien d'autre n'est installé sur le Mac.
  3. Saisissez l'adresse IP notée à l'étape 1.
  4. Sur la TV, un message demande d'autoriser le Mac : cochez « Toujours autoriser cet ordinateur » puis validez. Revenez sur le Mac et cliquez sur « Réessayer » si besoin.

Le kit enregistre alors une sauvegarde de l'état de la box, sans rien modifier. Ensuite il demande :

Votre ville (facultatif)
Pour afficher la météo. Le nom de la ville est envoyé au service gratuit Open-Meteo pour trouver sa position. Laissez vide pour ne pas avoir de météo.
Un jeton TMDB (facultatif)
Pour afficher les films et les bandes-annonces. Sans lui, tout fonctionne sauf les films. Pour l'obtenir, gratuitement :
  1. créez un compte sur www.themoviedb.org ;
  2. ouvrez Paramètres, puis API ;
  3. copiez le « API Read Access Token » (un très long texte) ;
  4. collez-le dans la fenêtre du kit (il reste masqué).
Les applis désactivées d'office
La liste de ce qui sera désactivé : publicité, pistage, rapports envoyés à Xiaomi ou Google, doublons de Zen Home.
Les options, une par une
Pour chaque programme optionnel, vous répondez Garder ou Désactiver. Un choix est proposé par défaut : la touche Entrée le valide. Voir la liste plus bas.
Vos propres applis
Le kit liste les applis que vous avez installées, avec leur taille et leur dernière utilisation. Rien n'est coché d'avance. Ne cochez que celles que vous voulez vraiment désinstaller : c'est définitif.
Le récapitulatif
Les applis ne sont désactivées ou désinstallées qu'après votre clic sur Appliquer.

À la fin, une fenêtre « Terminé » résume ce qui a été fait. La TV affiche alors Zen Home.

Après coup

Après une mise à jour de la box

Une mise à jour de la box peut réactiver certains programmes ou remettre l'ancien accueil. Réactivez le débogage USB si vous l'aviez coupé, relancez « Zen Home.command » et choisissez Réparer (après une mise à jour de la box). Vos choix précédents sont conservés.

Revenir en arrière

Relancez « Zen Home.command » et choisissez Tout annuler : toutes les applis désactivées sont réactivées, l'accueil d'origine revient et Zen Home est retiré. Les applis que vous aviez désinstallées ne reviennent pas.

La sauvegarde et le rapport

À chaque lancement, le kit crée un dossier daté dans Documents / Zen Home / sauvegardes. Vous y trouvez l'état de la box avant modification (listes d'applis, réglages) et le fichier rapport.txt qui raconte ce qui a été fait. Gardez-le si vous demandez de l'aide.

Sécurité : coupez le débogage USB

Tant que le débogage USB est activé, n'importe quel appareil de votre réseau Wi-Fi qui a été autorisé peut piloter la box. À la fin, le kit vous propose de le couper : acceptez. Vous pourrez le réactiver (même chemin qu'à l'étape 1) pour utiliser « Réparer » ou « Tout annuler ».

Les options proposées et leurs conséquences

Si vous hésitez, gardez : vous pourrez changer d'avis en relançant le kit. Sont proposés « gardés » par défaut : la recherche vocale et les deux services de mise à jour Xiaomi ; les autres options sont proposées « désactivées » par défaut.

Recherche vocale (gardée par défaut)
Le bouton micro de la télécommande. Si vous la désactivez, le micro ne fera plus rien, mais vous libérez environ 115 Mo de mémoire.
Chaînes en direct
Sert aux tuners TV. La Mi Box n'en a pas, l'appli tourne pour rien.
Synthèse vocale
Lit les textes à voix haute pour le lecteur d'écran. Inutile si personne n'en a besoin, libère environ 300 Mo.
Lecteur d'écran (TalkBack)
Aide pour les personnes malvoyantes. Inutile si personne n'en a besoin.
Mi Link
Diffuser depuis un téléphone Xiaomi. Le Chromecast intégré reste disponible pour tous les téléphones.
Lecteur vidéo Xiaomi
Lit les vidéos d'une clé USB. Gardez-le si vous regardez des fichiers sur clé USB.
Play Jeux
L'appli de jeux Google. Gardez-la si vous jouez sur la box.
YouTube Music
Gardez-la si vous écoutez de la musique avec.
Google TV (films Google)
Location et achat de films chez Google. Gardez-la si vous en avez acheté.
Appareil photo
La box n'a pas de caméra.
Impression
La box ne sert pas à imprimer.
Mises à jour Xiaomi (gardées par défaut)
Installe les mises à jour de sécurité de la box. Recommandé de garder.
Téléchargements Xiaomi (gardés par défaut)
Utilisé par les mises à jour Xiaomi. Recommandé de garder.

Si ça ne marche pas

  • « La box ne répond pas » : vérifiez que la box est allumée (pas en veille), que le débogage USB est activé, que l'adresse IP est la bonne (elle peut changer après un redémarrage) et que Mac et box sont sur le même Wi-Fi.
  • La fenêtre d'autorisation n'apparaît pas sur la TV : désactivez puis réactivez le débogage USB sur la box, et relancez le kit.
