# Format (lu par le kit d'installation, textes affichés aux utilisateurs) :
#   paquet  # [balise] Libellé : explication
# Tout paquet est au choix dans le kit ; la balise ne fixe que le choix recommandé :
# Sans balise         : à désactiver (pistage, pub, remplacé par Zen Home).
# [option]            : à désactiver, mais utile à certains.
# [option:garder]     : à garder.
# Les paquets gardés sont notés sur la box dans settings global zenhome_garder et verifier-tv.sh --fix les laisse actifs.
# Un nouveau paquet de la liste est désactivé par --fix tant qu'il n'est pas noté comme gardé.
# Pas de « | » ni de saut de ligne dans les textes.
